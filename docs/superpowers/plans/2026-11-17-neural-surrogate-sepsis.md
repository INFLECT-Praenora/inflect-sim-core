# Neural Surrogate of the Sepsis SBML Model — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train a viva-torch neural surrogate of the sepsis SBML model, run it as a drop-in `NeuralProcess`, and compare it to the real CVODE model on accuracy and speed — shipped as the `neural-surrogate-sepsis` investigation in simulation-core.

**Architecture:** The surrogate's Markov state is the model's **91 rate-rule variables** (empirically: 0 floating species, 91 rate rules). Task 1 exposes those as a readable, stably-ordered process-bigraph state path on the sepsis composite; viva-torch's `TrajectorySampler` reads that path (plus the 9 observables, carried as extra targets so they are comparable at inference without roadrunner) to build a `TransitionDataset`; `train_surrogate` fits a residual-MLP; `evaluate_surrogate` + bespoke harnesses produce accuracy and speed comparisons. Four studies (`01-sample-and-train`, `02-accuracy`, `03-speed`, `04-where-it-breaks`) carry findings + figures.

**Tech Stack:** Python 3.12, process-bigraph, viva-tellurium/roadrunner (CVODE), viva-torch (PyTorch residual-MLP), matplotlib, pytest, the viva-superpowers investigation/report tooling.

**Spec:** `docs/superpowers/specs/2026-11-17-neural-surrogate-sepsis-design.md`

## Review Focus

- **Rate-rule id↔value alignment & order stability:** the exposed 91-vector must be ordered identically at t=0, after a step, and across runs; a mismatch silently trains the net on scrambled state. Pinned by Task 1's test asserting ids are a fixed ordered list and values equal `getRateRuleValues()` element-wise.
- **Train/eval distribution separation (OOD honesty):** accuracy (study 02) must be measured on **held-out initial conditions** inside the training distribution; OOD severity is study 04 only. Pinned by Task 3 recording the train/eval IC split and Task 5 asserting eval ICs ∉ train ICs.
- **Speed-measurement fairness:** surrogate vs CVODE timed over the **same horizon + interval**, both warm (first roadrunner run has cold-start cost). Pinned by Task 6 asserting matched horizon/interval and discarding a warmup run.
- **torch not leaking into default CI:** importing `viva_simulation_core` (and running the non-slow suite) must succeed with torch absent. Pinned by Task 2's test that the surrogate module import-guards torch and the package top level does not import it.
- **Observable recoverability at inference:** the 9 observables must be comparable from the surrogate alone (no roadrunner). Pinned by Task 3 including them as targets and Task 5 computing their nRMSE from the surrogate rollout.
