Composition — one sepsis spec, interchangeable engines

Q Does the same sepsis specification run under interchangeable engines by swapping one box — BioGears (C++ physiology), the exact SBML extraction (Tellurium/CVODE), and a PyTorch surrogate — all through one typed-port interface?

Claim

The same sepsis core runs under three interchangeable engines — BioGears (C++), Tellurium (exact SBML via roadrunner/CVODE), and a PyTorch surrogate — each a box over the same typed observable ports. Swapping engines is swapping one box's address. The nine-observable overlay shows the two full-physics engines (BioGears and exact Tellurium) run the same spec and track to within ~0.1% on the inflammation core; the surrogate is the third interchangeable engine (its speed and approximate behavior are study 04). Where the full-physics engines diverge — the hemodynamic layer — is the fidelity backbone (study 05).
