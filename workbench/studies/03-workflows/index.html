Claim

The simulation core composes registered modules into a workflow and hands an Antimony/SBML file between engines, using the four-verb API and no new simulation code. The BioGears sepsis core — extracted to the portable file biogears_sepsis.ant — is handed to the TelluriumUTCStep engine (load the file, run it), composed in one workflow with a NeuralProcess surrogate tier and a MathExpressionStep derivation, and run end-to-end in a few seconds. The four verbs (list -> call -> connect -> run) are the entire surface; the portable artifact is the interface between engines.

Background

Question Can the simulation core compose registered modules into a workflow and hand an Antimony/SBML file between engines — all through a small, uniform API, with no new simulation code?

Model & approach

Demonstrate the orchestration pillar: build and run a pipeline with the four-verb workflow API (list modules, call one, connect a workflow, run it), where the portable biogears_sepsis.ant artifact is handed to the Tellurium engine and the pipeline composes it with a surrogate tier and a derivation step.
