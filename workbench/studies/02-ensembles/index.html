Claim

The sepsis core runs as a severity {0,1,3} × engine {BioGears, Tellurium, surrogate} ensemble, gathered into one grid. The two full-physics engines agree to within ~0.1% and show the expected severity response (minimum tissue integrity 1.00 healthy -> 0.97 mild -> 0.24 severe); their heavy runs are cited from the committed severity studies. Background

Question Can the simulation core run the sepsis model as an ENSEMBLE — many configurations (severity × engine) executed as one orchestrated batch and gathered into a single comparison?

Model & approach

Demonstrate the ensembles pillar: run the sepsis core across severities {0,1,3} under multiple engines and gather one endpoint (minimum tissue integrity) into one grid — the same batch harness that would run any registered engine.

the-surrogate-ran-live-across other supported literature
Why: The batch makes two different kinds of claim, and the apparent divergence sits entirely at the boundary between them. BioGears and the exact Tellurium extraction — two independently built full-physics engines — agree to within ~0.1% on minimum tissue integrity across severities {0,1,3} (1.00 healthy -> 0.968 mild -> 0.243 severe). Because they are separate implementations, that agreement is cross-engine replication: the severity response is a property of the shared model, not an artifact of one engine. That is the fidelity claim this study supports. The surrogate is a different tier. Its tissue-integrity endpoint is out of physical range, so it is not a third physical estimate competing with the full-physics pair; reading it that way would be wrong. Its presence in every cell proves only what it is meant to: the harness orchestrates many cheap configurations in one sweep (the throughput claim, quantified in study 04). The divergence is by design, not an unresolved contradiction. The full-physics engines answer 'does the model show the expected, engine-independent severity response?' (yes); the surrogate answers 'can the batch harness fan a cheap engine across the whole grid live?' (yes). Neither bears on the other. The open question the divergence makes visible is whether the surrogate can be moved from orchestration-proof to a science-grade tier at all. This grid cannot decide that; it needs a held-out quantitative fidelity test for the surrogate against the full-physics endpoints, which is the work deferred to study 05. Until that test exists, the surrogate's number stays reported for transparency and excluded from any fidelity claim.
